# 🎓 University Rankings Pipeline

A full-stack data pipeline and dashboard that aggregates university ranking data from multiple sources, normalizes scoring systems, calculates composite rankings, and displays results in a modern web dashboard.

## 🚀 Live Features

- Pulls ranking data from multiple sources
- Normalizes different scoring systems
- Composite weighted ranking engine
- REST API with Express.js
- PostgreSQL database integration
- React + Vite frontend dashboard
- Search universities
- Refresh rankings dynamically

## 🛠 Tech Stack

### Backend
- Node.js
- Express.js
- PostgreSQL
- Axios
- Node-Cron

### Frontend
- React
- Vite
- CSS

## 📂 Project Structure

frontend/ → React dashboard  
src/ → Backend API  
scripts/ → Utility scripts
